5.DESIGN REFLECTION
For my application, I wanted to make something that can help a chef keep track of the menu items. The application allows the chef to enter the name of a dish, add a description, choose what course it is, and enter the price. I think this meets the chef’s requirement because all the important information about a menu item can be added and saved in one place. The chef can also see the menu items that have already been added.
For the React Native Components, I chose ones that I think are easy for the user to understand. I used the Text component for headings, because it is mainly used to show information on the screen. I used TextInput for entering the dish name, description and price because the user needs to type this information. I used a picker for selecting the course, which makes it easier because the chef can just choose an option instead of typing it.
I also used Button for saving the menu item. This makes it clear to the user what they need to press when they are finished entering the information, lastly, I used a FlatList to display the menu items. This is useful because if the chef has many dishes, they can all be shown in a list.
Overall, I think my design is fairly simple and user-friendly. I tried not to make it to complicated so the chef can use it without getting confused.
